# 小算狸 Codex 视频创作

**简体中文** · [English](README.en.md)

官网：[www.xiaosuanli.com](https://www.xiaosuanli.com)

**在 Codex 中通过本地 MCP 和对话生成、修改并导出 AI 视频。**

一句创意、一篇故事或一段参考视频，都可以成为作品的起点。告诉 Codex 你想拍什么、需要什么画风和时长，再通过聊天推进制作和修改。

## 安装

在 Codex 对话中发送：

> 安装 https://github.com/xiaosuanli/codex-creative/blob/master/xiaosuanli-director/SKILL.md，请安装完整 Skill 目录并配置本地小算狸 MCP。

安装后，Codex 会配置本地小算狸 MCP，并引导你完成首次连接：

1. 按提示重新加载或重启 Codex，在 `/hooks` 中审阅并信任小算狸消息钩子，然后发送一条新消息。可使用 `/mcp` 查看 `xiaosuanli` 是否已连接。
2. 按 Codex 给出的链接打开小算狸授权页面，登录并确认授权，将网页提供的一次性授权码发回当前对话。
3. 选择工程和章节，然后告诉 Codex 你想制作什么。没有工程时，也可以让 Codex 帮你创建。

Codex 会使用已有的 Python；如果没有，会提示你安装。你需要一个[小算狸账号](https://www.xiaosuanli.com)；图片和视频生成可能消耗积分或权益。

## 你可以这样创作

| 想做什么 | 可以对 Codex 说 |
| --- | --- |
| 生成创意短片 | 帮我做一段 30 秒的科幻短片，写实电影风格。 |
| 把故事或小说拍成视频 | 把这一章浓缩成两分钟的动画短片，保留结尾反转。 |
| 参考视频再创作 | 参考我上传的视频，保留主要剧情，换成水墨动画。 |
| 修改已有工程 | 把第二个镜头改成近景，人物语气更犹豫。 |
| 继续制作并导出 | 继续完成这一章，导出完整视频。 |

例如，可以直接说“创建一个叫《我的第一部短片》的工程”。

作品保存在小算狸导演工程中，你可以打开 Codex 返回的编辑链接，在网页上继续调整。单章文本最多 20,000 字，导入的参考视频为 15～180 秒；具体能力以账号权限和实际返回结果为准。
