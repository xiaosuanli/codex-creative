# 小算狸 Codex 视频创作 Skill

在 Codex 中通过对话创作和编辑小算狸导演工程：把创意、故事或小说制作成视频，也可以解析参考视频、调整分镜和素材，继续生成并导出成片。作品保存在小算狸账号中，可以在导演台网页继续编辑。

## 安装

在 Codex 对话中发送：

> 安装 https://github.com/xiaosuanli/codex-creative/blob/master/xiaosuanli-director/SKILL.md

需要 Node.js 22.19 或更高版本和[小算狸账号](https://www.xiaosuanli.com)。Codex 会安装完整 skill；首次使用时配置消息钩子，并提示你在 `/hooks` 审阅和信任，然后发送一条新消息继续。

## 开始创作

在 Codex 中说：

> 使用小算狸导演，帮我把这个故事拍成一分钟的动画短片。

Codex 会在对话中引导账号授权、工程和章节选择，然后按你的要求制作。也可以说“创建一个名为《我的短片》的工程”，或让它继续已有章节、修改指定镜头、查询进度和导出成片。需要参考视频时，按提示在导演台上传并选择素材。

图片与视频生成可能消耗账号积分或权益；安装 skill 不会自动生成。单章文本最多 20,000 字，导入的参考视频为 15～180 秒。具体能力和权限以服务端返回为准。
